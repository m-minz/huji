# שנתון האוניברסיטה העברית (HUJI Shnaton) 🎓

ממשק אינטרנטי מודרני, מהיר ורספונסיבי לשנתון האוניברסיטה העברית בירושלים.
האתר פועל **100% בצד לקוח (Client-Side)** ומתארח בחינם על גבי **GitHub Pages** באמצעות מנוע SQLite ב-WebAssembly (`sql.js`).

## ✨ תכונות עיקריות
- 🔍 **חיפוש מהיר בקטלוג**: חיפוש לפי שם קורס, מספר, פקולטה, חוג, מרצה, נקודות זכות וסמסטר.
- 📖 **סילבוסים ודרישות**: תיאור הקורס, מטרות, תוצרי למידה, דרישות קדם והרכב ציון.
- 📝 **לוח בחינות אינטראקטיבי**: צפייה בכל מועדי א', ב', חדרים ושעות הבחינה.
- 🏛️ **תפוסת כיתות שבועית (08:00–20:00)**: חיפוש כל אולם/כיתה וצפייה במערכת השעות והחלונות הפנויים.
- 👨‍🏫 **מאגר מרצים**: צפייה בכל הקורסים ושעות ההוראה של כל איש סגל.
- 🗺️ **מפת קמפוס**: ניווט ישיר לאולמות ומבנים לפי קמפוס.
- 📅 **מערכת שעות אישית**: הרכבת מערכת שעות שבועית עם זיהוי התנגשויות.
- 📱 **רספונסיביות מלאה**: מותאם בצורה אופטימלית לטלפונים ניידים, טאבלטים ומחשבים שולחניים.

---

## ⚡ טכנולוגיה וארכיטקטורה
- **WebAssembly SQLite (`sql.js`)**: מסד הנתונים השלם (47,000 קורסים) רץ ישירות בדפדפן המשתמש ללא צורך בשרת אחורי.
- **זיכרון מקומי (IndexedDB)**: מסד הנתונים נשמר מקומית במכשיר לאחר ההורדה הראשונה, ומאפשר טעינה מיידית (0.05 שניות) ועבודה מלאה גם ללא חיבור לאינטרנט (Offline).
- **דחיסה יעילה**: קובץ הנתונים `shnaton.db.gz` שוקל כ-18.7MB בלבד.

## 🔄 רענון מסד הנתונים

### 1. רענון בענן באמצעות GitHub Actions (ללא צורך במחשב)
1. היכנס לטאב **Actions** במאגר ב-GitHub.
2. בחר ב-**Refresh Shnaton Database & Deploy**.
3. לחץ על **Run workflow** ובחר את סוג הרענון (`exams` לבחינות בלבד בכ-2 דקות, או `full` לסריקה מלאה).
4. ה-Action ימשוך נתונים עדכניים משרתי האוניברסיטה, יעדכן את מסד הנתונים ויפרוס את השינויים אוטומטית לאתר!

### 2. רענון מקומי
הפעל את הקובץ:
```bat
רענן_מסד_נתונים.bat
```
ובחר את סוג הרענון הרצוי.

## 🚀 פריסה ל-GitHub Pages
1. בהגדרות המאגר ב-GitHub: **Settings** -> **Pages**.
2. תחת **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/(root)`
3. לחץ **Save**. האתר יהיה זמין תוך כדקה בכתובת:
   `https://<username>.github.io/<repo-name>/`
